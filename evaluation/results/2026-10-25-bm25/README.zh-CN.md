## 复现

在 `backend`，将 project UUID 替换成严格匹配冻结语料的准备项目，输出目录必须全新：

```powershell
.\.venv\Scripts\python.exe -m scripts.run_evaluation --dataset ..\evaluation --project-id YOUR_EVAL_PROJECT_UUID --output-dir ..\output\evaluation\bm25-replay --modes keyword bm25 --top-k 5
```

不添加 `--allow-embedding-calls` 或 `--with-answers`，不需要供应商凭据。运行器检查来源与图谱指纹，拒绝语料外来源或运行期间漂移。协议、分词和资源上限见 [ADR 0044](../../../docs/adr/0044-bounded-offline-bm25-search.zh-CN.md)。旧的向量/混合/回答实验不覆盖、不重新计费。
