# 真实上游技术文档测试集 v3


7 份完整、MIT 许可、固定提交的 FastAPI 技术文档，新增 24 题：8 直接、8 跨文档、4 历史、4 无答案。语料是真实上游文档，不冒充用户私人笔记。文档中的代码 include 指令保留原样，不表示已经导入被引用代码。

原上游相对链接按字节保留，应在固定提交的上游目录解析，不在本地部分语料中解析；不代表链接页已导入。

旧合成 v1 和 public-v2 作为开发集；v3 全部文档主题和同一文档的两个历史版本都在测试侧。不得使用这些题调整排序、提示词或阈值。协议与原始字节指纹在供应商实验前冻结；题目/金标由 Agent 编制，仍需独立人工审核，没有生成任何人工分数。

历史可用时间来自 0.94.1 / 0.95.0 发布提交。隔离研究中的普通审核回放替代的是旧文档快照，不代表旧 API 失效，也不证明真实个人笔记时间或某项功能的首次引入时间。

在 backend 离线校验：`python -m scripts.prepare_evaluation --dataset ../evaluation/holdout-v3 --validate-only`。本轮没有运行付费实验，不产生新的答案质量结论。后续实验须使用新结果目录和既有累计账本，不能重置 120 次模型 /160 次嵌入授权。

现有 public-v2 的 80 行盲评表位于 `evaluation/results/2026-10-26-public-v2-run1/blind-review.html`。真实评审本地填写并导出 CSV，再用 `scripts.review_public score` 导入新目录。空白正确性/解释性保持缺失；用户已选择稍后填写。

独立性在文档/题目层面：public-v2 已有 FastAPI 代码片段，同一框架及部分概念仍有交集，不属于未见仓库或未见领域测试。source-family 划分保证 v3 历史版本不跨集合，不表示开发集完全没有相关上游概念。
