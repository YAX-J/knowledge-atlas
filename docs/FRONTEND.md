# Knowledge Atlas 前端开发说明

本文说明当前前端的结构、交互和后端接入方式。图谱与模拟问答来自 `src/mock/data.ts`，可独立运行；项目与资料工作台使用真实后端接口。

## 技术栈

- Vue 3 Composition API
- TypeScript
- Vite
- Element Plus 图标与消息提示
- 原生 SVG 知识图谱
- CSS 响应式布局

当前图谱使用原生 SVG，是为了精确还原原型并控制节点形状、关系标签和时间状态。后续数据量超过约 200 个可见节点，或需要复杂布局、拖拽和聚类时，再评估迁移到 AntV G6。

## 启动与构建

```bash
cd frontend
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

`npm run build` 会先执行 Vue TypeScript 检查，再生成生产资源。

## 当前页面状态

`App.vue` 维护以下页面级状态：

| 状态 | 用途 |
| --- | --- |
| `selectedId` | 当前选中的知识节点 |
| `timelineIndex` | 当前查看的知识时间点 |
| `visibleTypes` | 当前显示的节点类型 |
| `panelOpen` | 详情侧栏或移动端抽屉是否打开 |
| `filterOpen` | 类型筛选面板是否打开 |

时间或类型变化后，如果当前选中节点不再可见，页面会自动切换到第一个可见节点，避免图谱和侧栏状态不一致。

`App.vue` 也维护项目与资料分页、当前项目/来源/任务、原文分块、各操作的加载/错误状态。网络操作集中在页面；`SourceWorkspace.vue` 只接收数据并发出用户意图。切换项目和资料时清空旧详情，并使用请求序号忽略迟到的响应。上传和任务执行期间阻止切换上下文，避免结果混入其他项目。

## 图谱交互

- 节点支持鼠标点击、Enter 和 Space 键选择。
- 当前节点使用双层酒红色描边，直接关联节点保持较高对比度。
- 项目、概念、决策、问题和代码实体使用不同形状与颜色。
- 关系标签使用等宽字体；与当前节点相关的边会高亮。
- 支持放大、缩小和重置视图。
- 类型筛选和时间轴会同时影响节点与关系。

## Mock 数据结构

核心类型定义位于 `src/types.ts`。

```ts
interface KnowledgeNode {
  id: string
  label: string
  subtitle: string
  type: NodeType
  x: number
  y: number
  size: number
  description: string
  confidence: number
  validFrom: string
  project: string
  evidenceIds: string[]
}
```

当前 `x`、`y` 和 `size` 只服务于演示布局。接入后端时，领域接口不应要求后端生成画布坐标；前端应根据返回数据计算布局，或单独保存用户调整后的视图配置。

## 响应式策略

- 桌面端使用“图谱工作区 + 详情侧栏”双栏布局。
- 中等宽度下详情侧栏变为右侧覆盖层。
- 手机端详情变为全屏抽屉，主导航移动到底部。
- 图谱保持足够大的内部画布，通过裁切显示核心区域。
- 所有主要按钮具有可见键盘焦点，并支持减少动态效果偏好。

## 接入真实 API

`src/api/` 已提供并接入项目创建/查询、项目资料分页、Markdown 上传、来源查询、任务查询/执行和原文分块分页。重复上传可能返回已有任务的当前状态，不能假设始终为 `queued`。请求默认 30 秒超时；不自动重试创建、上传或执行请求，结果未确认时提示刷新后重试。

通过 `VITE_API_BASE_URL` 配置后端地址。`VITE_DATA_SOURCE=mock` 默认打开演示图谱，进入项目/资料页才请求后端；`VITE_DATA_SOURCE=api` 默认打开资料工作台。两种配置下，图谱与问答都仍使用 Mock，页面已明确标注；后端不可用时资料页显示错误和重试，不回退为伪造资料。环境变量修改后需要重启开发服务器。

### 验证资料流程

1. 进入“我的项目”，创建一个项目，确认列表和当前项目更新。
2. 上传 UTF-8 `.md` / `.markdown` 文件，核对原文预览与待解析状态。
3. 点击“开始解析”，核对完成状态、标题路径和原文行号；失败任务可“重试解析”。
4. 使用超过 20 个分块的文件核对翻页；重复上传同一内容应复用资料。
5. 刷新页面后再次进入资料页，确认从后端重新读取项目、资料和任务。
6. 切换到另一个项目，核对原项目资料与详情不再显示。
7. 后端不可用时检查错误与重试入口，恢复后刷新；核对文件扩展名、编码校验。
8. 在桌面和手机宽度检查滚动、键盘焦点、长文件名、空数据和无障碍名称。分块使用文本插值，不能执行原文中的 HTML/脚本。

后续在图谱接口完成后增加知识数据适配层与问答客户端。演示夹具继续保留在 `mock/data.ts`，服务端检索、流式问答和图谱布局属于后续开发。

接口草案见 [API_CONTRACT.md](API_CONTRACT.md)。

## 已知限制

- 问答记录入口目前仅显示阶段提示；真实图谱和问答尚未接入。
- 页面刷新后默认选中返回列表中的首个项目和资料，尚未保存路由或视图偏好。
- 搜索只匹配本地 Mock 数据，没有拼音、别名和服务端检索。
- 图谱节点位置固定，尚不支持拖拽、自动布局和框选。
- 问答内容是延时生成的模拟结果，不代表真实模型能力。
- 当前没有组件单元测试和端到端测试脚本。
