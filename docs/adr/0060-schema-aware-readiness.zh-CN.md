# ADR 0060 检查数据库结构的就绪状态

[English](0060-schema-aware-readiness.md)

- 状态：已接受
- 日期：2026-10-29

## 决策

`/health/live` 只检查进程；`/health/ready` 检查数据库连接、当前 schema 实际拥有的 Alembic 版本表及精确 head、六张工作台表和快照 scan_state 列。未迁移、版本落后、假标记或结构不完整返回 503 和安全的依赖说明。回归测试核对预期 head 与 Alembic；私有 search_path 必须拥有版本表，不能回退 public。

已有应用库升级前先备份并验证隔离 schema 恢复，不在健康检查/启动时自动升级。本轮接受的升级为 0017→0018，按统一 UTC 格式校验 18 张原业务表内容一致，备份只保存在本地忽略目录。

## 影响

连接成功不再等于业务路由可用。这是关键结构检查，不是完整数据一致性审计。后续迁移需同步 guard 和回归；免费就绪检查不探测供应商。
