# ADR 0073：OpenRouter Jev 评审

[English](0073-openrouter-jev-evaluation.md)

- 状态：接受
- 日期：2026-10-30
- 在 ADR0070/0072 基础上增加第三个离线评审供应商。

## 决策

显式新增 OpenRouter Jev Decisions API，独立本地凭据和明确发布/快照模型字段。复用已有 httpx、Choice 校验、供应商无关匿名包和逐次落盘预留。使用固定官方 Decisions 地址，禁用供应商回退、保留环境代理，transport 重试0次。旧供应商标记不能授权另一供应商。

接受请求发布版本或其日期快照，显式快照必须精确匹配。记录请求/实际模型、实际 token 计数和可选供应商费用；模型漂移时停止并保留全部尝试/完成结果，发布选择不标记不可变。静态脱敏错误区分认证/付款/限流及超时阶段，保留大小上限并拒绝非法 JSON/Choice/用量。

## 影响

不改业务供应商、API、页面、迁移、入图或人工评分，人工评分覆盖率仍为0%。CF 原生支持不变，不实现其第三方 Jev 路由。冻结结果/holdout/旧账本不变，新真实运行均需明确授权；HTTP 替身不证明账号资格或裁判质量。见[配置与命令](../OPENROUTER_EVALUATION.zh-CN.md)。

## 验证

OpenRouter/CF/Jev/实验聚焦回归132通过；KA_NATIVE_COMPILERS=1 完整后端915通过、8跳过，应用语句覆盖率95.75%，90%门禁通过。实际 CLI 准备及 OpenRouter/直连Jev/原生CF 预演各计划54次，预留/完成/模型评分均0、人工评分0。343个本地 Markdown 目标存在，双语同步，git diff --check 和暂存审查通过。本地 .env 仍忽略，冻结输入/结果/旧账本不进入变更；未改前端/页面/SQL/迁移，因此未重复浏览器/构建/原生数据库验收。真实调用0，账号/付款/模型质量尚未验证。
