# ADR 0022：解析通过显式声明接收者发起的有界 Java 调用


- 状态：Accepted
- 日期：2026-10-21

## 背景

ADR 0017 有意把跨文件 Java 方法提示限制在直接类型限定接收者和当前类型字段接收者。代表性的服务代码还会把协作者作为方法参数传入，或赋给简单的方法局部变量；即使声明类型明确且位于同一仓库，这些调用此前也无法连接。

## 决策

- 扩展既有按需派生的 `cross_file_calls`，不改变响应形状、持久化模型、仓库/来源/字节上限或正式图谱边界。
- 从方法参数以及方法体直属作用域内的单变量声明读取显式类型；局部变量调用只在声明出现后解析。
- 对未限定接收者采用接近 Java 的遮蔽优先级：最近的可用直属局部声明、方法参数、当前类型字段。显式 `this.field` 始终选择字段；继续支持大写形式的直接类型限定调用。
- 继续按显式导入、当前包与通配导入解析声明类型；目标方法仍只按名称匹配，并保留既有 `resolved` / `ambiguous` 语义和确定性 ID。
- 忽略 `var`、多变量声明、嵌套块局部变量、重新赋值/数据流、链式/工厂接收者、继承分派、重载选择和外部类路径。

## 影响

- 常见的参数注入和简单方法局部协作者调用现在可以连接到仓库内的方法声明，同时保留精确调用行与目标行。
- 字段遮蔽得到保守表达：`validator.run()` 可以跟随参数/局部声明，而 `this.validator.run()` 仍跟随字段声明。
- 结果仍是有界语法提示，不是完整 Java 调用图；复杂作用域、推断和分派在引入真实解析器与符号求解器前不会被宣称支持。
