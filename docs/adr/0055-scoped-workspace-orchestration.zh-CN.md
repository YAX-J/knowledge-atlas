# ADR 0055：按上下文分离工作台编排

状态：已接受 · 日期：2026-10-26


## 决策

导入写入移到 useSourceImport，候选抽取/筛选/审核移到 useCandidateReview，图谱读取/详情选择移到 useProjectGraph；新增停用写入/审计读取由 useKnowledgeRetirement 管理。保留组件 props/events、接口契约；项目导航、来源详情/证据定位和演化编排继续在 App 中。不引入路由或全局状态库。

模块拥有请求序号及同步上下文/卸载失效机制，包括离开后回到同一项目/资料/时间。导入模块只接类型化 refs 和选择、列表/详情刷新、共享写入守卫等窄回调；上传不会隐式触发抽取。保留文件夹部分成功及显式远程操作。刷新失败也释放上传锁，卸载后不再继续发送其他文件写入；卸载不取消已经发给服务端的写入。App 保留跨流程导航锁。

## 影响

App 从 1326 行变为 971 行；行数不是质量评分。继续复用 useLatestRequest/useKnowledgeSearch。既有 App 事件回归、新模块生命周期测试及真实桌面原生 API 流程共同保护行为。覆盖率明确纳入新模块与停用组件，配置范围百分比不能描述全应用。仓库快照、资料读取/定位与演化编排保留为后续可独立拆分职责，本轮不整体搬迁。
