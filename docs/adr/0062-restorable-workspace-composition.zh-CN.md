# ADR 0062 可恢复的工作台与模块编排

[English](0062-restorable-workspace-composition.md)

- 状态：已接受
- 日期：2026-10-29

## 决策

扩展 ADR 0055，hash URL 保存项目/资料/实体/关系/时间/会话及图谱任务区，不增加服务端 rewrite 或状态库。URL 只放标识和时间，不放问题/原文。通过有作用域的 API 读取恢复，失效链接显示错误/明确重试；主动导航使迟到恢复失效，写入期间拒绝切上下文。恢复会话只读历史，不重新提问。

图谱分为关系/检索/身份/演化/停用，保持当前知识和时间。原文定位、快照列表/文件/导入、演化/治理/对照分别拆入生命周期组合模块；App 连接共享上下文与写锁，展示组件仍用 props/events。请求代数和卸载继续拒绝迟到响应。

## 影响

刷新与浏览器历史恢复工作位置而不重放写入；不持久化搜索草稿、分析策略/版本或未提交表单。hash ID 仍需后端授权。本决策取代路由尚无必要时将所有编排留在 App 的早期建议。
