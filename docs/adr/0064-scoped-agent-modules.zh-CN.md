# ADR 0064 现有应用内的受限 Agent 模块


- Status: Accepted
- Date: 2026-10-29

## 决策

继续使用同一个后端/前端项目，在 `backend/app` 内分出 `agents`、`workflows`、只读 `tools`、`analysis` 和 `llm`。注册代码分析、知识抽取、证据问答三个角色。Agent 接收不可变来源快照或有范围的只读回调，不接收数据库 Session。应用服务继续负责授权、结构/证据校验、事务和人工入图。迁移过的旧 service 导入路径作为规范模块的别名，保持旧接口与测试替换兼容。原生编译器辅助程序继续放在现有 scripts 目录。

固定 LangGraph 依赖版本，实现有界模型/工具循环和显式协作流程。角色共享用户/项目/资料/快照/时间/任务上下文及原子尝试计数。限制单角色和全流程的请求/工具/文本/时间预算，失败尝试同样计数，不自动付费重试。图调用关闭外部追踪上传。事件只包含固定词汇与数字，不保存原始提示词/工具参数。原文与工具输出是不可信数据。代码派生结果只作提示，不作正式证据或直接入图。

## 结果

新增 Agent 有统一注册和流程扩展位置，复用供应商和应用。原有解析 Worker、单轮接口保持兼容；依赖体积增加。有界串行流程不代表任意自主规划、生产认证或完整构建/运行时语义。正式入图仍须人工审核。见[实现说明](../MULTI_AGENT.zh-CN.md)。
