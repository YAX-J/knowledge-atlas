# ADR 0010：融合一跳图信号的可解释混合检索

[English](0010-explainable-hybrid-graph-retrieval.md)

- 状态：已接受
- 日期：2026-10-18

## 决策

在现有项目搜索接口中增加 `mode=hybrid`，对可见正式实体融合三种有界、项目内信号：

- 关键词：沿用确定性关键词得分，并按候选池中的最高关键词得分归一化；
- 向量：将余弦相似度截断到 `0..1` 的贡献范围；
- 图关系：从其他关键词/向量种子出发，取最强的可见一跳关系，以种子的最强归一化检索信号乘关系置信度。

最终得分为 `0.3 * keyword + 0.4 * vector + 0.3 * graph`。关键词和向量各最多提供 100 个种子；图扩展最多读取 500 条可见关系，并遵守用户、项目、类型、状态和有效时间边界。仅由图关系召回的邻居也可进入结果集。

混合响应返回固定权重、归一化关键词/向量分量、图得分、最终得分，以及每条结果最多 3 条关系解释；继续返回原文证据，并按得分、名称和 UUID 稳定排序。该操作只读，但与向量搜索一样依赖显式构建的语义索引和嵌入服务配置。

## 后果

- 排序可以检查和复算，不需要暴露模型内部推理。
- 已归档、时间不可见、跨项目或其他不可见关系不会影响图得分。
- 候选与关系上限约束查询成本，但不代表对整张图做穷尽排序。
- 固定权重是实验基线，不代表已经证明最优。
- 本决策不实现问答、多跳图遍历、重排、实体消歧或自动索引更新。
