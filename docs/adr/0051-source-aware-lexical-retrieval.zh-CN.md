# ADR 0051：可选的来源位置词法检索

[English](0051-source-aware-lexical-retrieval.md)

状态：已接受

日期：2026-10-25

## 决策

新增可选 `mode=bm25_source` 及问答 `retrieval_mode=bm25_source`。协议 `mixed-bm25-source-v1` 将证据来源的原文件名、相对路径与分块标题作为 `provenance` 字段，在既有单实体文本预算内先于摘录参与排序。分词、BM25 参数及实体/证据/时间/租户边界不变。只读取通过正式证据关联的来源，未审核资料或代码结构不作为回答知识。仅命中位置时仍返回原始精确证据和规范 ID。标题最多贡献 512 字符，截断会报告。

保留原 bm25、关键词、固定混合、向量、RRF 和所有默认值；新模式实验单独记录协议并写入新目录。来源路径是位置上下文，不证明任意语义结论成立。引用 ID 校验、证据预算及证据不足响应约束保留。

## 影响

用户可明确按代码文件/路径或标题检索已审核知识，无需嵌入。9 个新增独立功能案例覆盖位置、无匹配及词面误导下的模拟拒答，是开发回归，不是盲测或代表性效果基准。旧 40 题开发集上两种模式 Recall@5 均为 74.49%，不提升为默认策略或声称总体更优。不新增模型调用或正式持久化对象。
