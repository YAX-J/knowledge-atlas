# ADR 0048：关系审核依赖可见性

[English](0048-review-endpoint-visibility.md)

状态：已接受

日期：2026-10-25

## 决策

候选列表为关系补充 `endpoints` 快照，包含去重后的可访问实体候选 ID、名称和审核状态；审核动作响应及实体候选默认返回空列表。补充读取独立于外层状态/类别/文字筛选和分页，以一次有界查询读取最多两倍页大小的端点 ID。每个端点必须与关系匹配用户、项目、资料、成功抽取任务，且类别为实体。缺失或不兼容的端点省略，不泄露其他作用域的名称或状态。

审核界面在实体卡片被筛除或位于其他页时，仍展示起点和终点状态。单项确认及修改后确认要求两端已确认；批量确认也接受本页明确选中的待审核实体，不自动添加任何端点。缺失、已拒绝或尚未选中的依赖会禁用最终确认，并显示具名原因；显式拒绝仍可执行。实体列表入口重置筛选和选择，聚焦审核标题，不执行审核或模型调用。

## 影响

用户可在提交前发现依赖问题。状态是读取时快照，可能过期；后端项目锁、依赖/证据重校验、审计幂等与原子回滚仍是最终依据。不改变提升规则、持久化结构、端点身份、撤销策略或模型行为，无需迁移或新增依赖。
