# ADR 0067 Agent 过程持久化与校验后的步骤检查点

[English](0067-durable-agent-progress.md)

- 状态：已接受
- 日期：2026-10-30
- 取代 ADR 0065 的仅结束时保存事件/用量规则；范围、显式人工审核、同步执行和只读重发保持。

## 决策

沿用 `agent_runs` 结构（`20261029_0019`）和既有接口形状。`RunContext` 接收应用层进度回调，Agent 不接收数据库 Session。每个事件保存无原文的元数据和用量；模型/工具/嵌入调用预留在执行回调前提交，随后失败的尝试同样计入。更新要求用户/项目/任务/执行 UUID 匹配、任务运行中、租约有效且项目未归档；在这些事件边界更新 1200 秒租约，保留原有时间及角色/全局预算。

`services/agent_progress.py` 只在共享请求会话没有 new/dirty/deleted ORM 写入的边界提交，进度更新期间关闭自动 flush；存在待完成写入则拒绝，不顺带提交未完成业务数据。抽取已经在调用供应商前提交认领，在调用后只保存校验通过的候选，检查点保留该事务边界。数据库失败转换为不含敏感信息的 `WORKFLOW_PROGRESS_UNAVAILABLE`，归属失效为 `WORKFLOW_INTERRUPTED`；关闭失败的保存回调并拒绝后续调用预留。初始进度回调失败时也恢复 Agent 上下文。

代码分析在既有校验后保存；抽取成功提交后保存任务/候选 ID；回答在引用校验后保存。对应事件为 `code_checkpoint`、`extraction_checkpoint`、`answer_checkpoint`，状态 `saved`。后续流程失败保留部分结果，不再改成 null；前端展示中文检查点标签。顶层任务状态仍为权威，部分结果中的步骤状态不表示整个流程完成。

## 影响与限制

同步 POST 期间 GET 可读取已提交进度。租约到期后，中断任务仍展示已保存的用量/事件/结果；读取、同 UUID 重发和既有审核恢复不调用供应商。这些检查点用于核查，不提供自动付费逐节点续跑、事件流或后台队列；长时间阻塞的回调没有独立心跳。调用前预留可能保守计入未发出的请求，不证明精确账单或供应商严格一次投递。仅已提交检查点可在进程崩溃后保留，候选提交与抽取检查点仍是两个事务。不需要迁移或新的真实供应商实验。

## 验证

本次继续沿用用户此前选择的 Agent 执行验证。2026-10-30 实际检查：

- 聚焦进度/协调器/工具/抽取/问答/会话测试：55 项通过。
- 完整后端，`KA_NATIVE_COMPILERS=1`：746 项通过，8 项显式外部/原生专用用例跳过，语句覆盖率 95.25%（门槛 90%）。
- PostgreSQL 17.10 / pgvector 0.8.7：自有 schema 中 169 项通过，包含迁移往返及独立连接在模型替身阻塞时观察已提交调用预留。临时 schema 已清理，应用迁移标记未变。
- 前端：16 文件、116 项测试通过，配置范围语句/行覆盖率 68.66%/73.42%，类型检查与生产构建通过。
- 桌面 Chrome、独立 agent-browser 会话、8011/5181 端口：检查空任务历史、显式本地替身抽取、等待人工审核、刷新恢复、编译器与问答、三类中文检查点标签、键盘焦点及事件面板滚动；无横向溢出或告警。浏览器和专用服务已关闭，浏览器临时 schema 已清理，截图保存在忽略的本地输出目录。

检查使用本地供应商替身/公开夹具，没有新增真实供应商请求或人工质量分数。历史验收及冻结实验文件保持不变；空白检查及 288 个本地 Markdown 链接目标通过。已确认专用 8011/5181 端口释放；截图和构建产物被忽略，不进入提交。
