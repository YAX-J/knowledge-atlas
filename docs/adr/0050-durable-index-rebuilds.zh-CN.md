# ADR 0050：持久化索引更新归属与未知结果


状态：已接受

日期：2026-10-25

## 决策

迁移 `20261025_0016` 新增每项目一行的 `embedding_jobs`，保存最近执行 UUID、用户归属、running/succeeded/failed、时间、结果和脱敏错误。既有显式同步更新接口在项目锁内认领并先提交执行归属，再请求供应商。并发运行请求返回 409；每批嵌入前续期 900 秒租约，向量落库前校验执行归属并持有项目锁。旧执行不能覆盖接手者状态或完成写入。接口仍为同步接口，不是后台队列。

零供应商读取 `GET /projects/{id}/embeddings/rebuild-status` 支持刷新页面后恢复状态；运行租约过期返回 `interrupted=true`，须显式 `retry_interrupted=true` 重新更新，不自动重试。中断请求的供应商计费不能回滚，也不保证严格只计费一次。成功写入保留既有哈希复用及事务行为。

客户端区分读取不可用和写入结果未知，包含成功响应体丢失/无效的情况。更新结果未知时提供状态查询，刷新状态期间保留运行锁，清空页面不表示取消服务端执行。等待预算：普通/本地读取 30 秒，向量检索与更新等待 240 秒，问答 420 秒，单步/工具调用分析 240/900 秒；超过浏览器等待时仍可查询持久化更新状态。

## 影响

索引更新可跨页面刷新查询，并在不同客户端间阻止重复运行。解析/抽取原租约独立；问答和调用分析仍不持久化，本轮没有将其改为可恢复任务。服务端进程丢失后须等待租约过期并明确重试。不新增框架、自动付费重试或正式知识修改。
