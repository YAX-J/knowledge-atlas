# ADR 0049：资料组合筛选与分页恢复

[English](0049-source-discovery-filters.md)

状态：已接受

日期：2026-10-25

## 决策

资料列表新增可选 `q`（最多 200 字符）、已注册的 `source_type` 和 `source_status=uploaded|processing|ready|failed`。q 规范化空白后对原文件名、仓库内相对路径作字面、不区分大小写的子串匹配，转义 SQL 通配符。全部条件在既有用户/项目/归档作用域内先筛选再计数、分页。默认结果、最近解析任务引用及 GitHub 溯源保持不变。状态筛选针对资料记录，与任务状态区分。

前端显式提交筛选，回到第一页，丢弃旧响应；切换项目重置条件。语言选项复用前端上传注册表，后端按自身权威注册表校验。当前已打开资料即使不在本页或筛选结果中也保留，并明确提示。筛选不会解析、抽取、审核或调用供应商。

请求页码独立于最后展示的响应保存，出错时重试失败页。成功响应表明目标页已不存在时，再请求最后一个有效页。应用筛选后仅在项目与已应用条件身份仍匹配时聚焦资料列表标题。原操作锁同样禁用筛选与列表操作。

## 影响

用户无需逐页翻找导入的笔记、代码和解析失败资料。不包含全文内容检索、仓库筛选、自动重试循环、迁移或新依赖。原文定位仍可独立于列表条件打开资料，不改变持久化资料身份或正式知识。
