# ADR0080：分离工程验收与项目 Agent 任务质量


状态：已接受 · 2026-10-31 · M5 离线准备

M1–M4 已有本地替身、原生数据库和浏览器证据，但不衡量通用任务完成率或语义引用支持。历史回答裁判不能验证笔记修改、审批、恢复和图谱变更。

采用独立虚构20项开发任务：证据、整理、代码、笔记、治理各4项。真实调用前冻结夹具、目标/范围、操作者步骤、预期、门槛和验收矩阵，用文件哈希与代码内可信摘要共同绑定。保留全部历史实验、holdout、结果、授权和账本。调试导致修改时另建任务包版本，最终质量工作使用全新任务。

M5 CLI 只负责校验、零调用预演、运行已有工程检查和汇总外部报告的任务/评分。它不能执行供应商、创建授权、审批提案、回填业务时间、推送或发布。预演记录实现/配置指纹及每任务共享8/16上限，预留和完成均为0，裁判为0。模型快照、金额估算和真实兼容性仍未验证；后续授权的真实执行器与隔离夹具重放属于独立工作。

工程子进程把命令、测试 XML、退出码、日志哈希和失败即停状态保存在新建的忽略目录。pytest 传输屏障阻止真实同步/异步 HTTP，保留 ASGI 和本地替身；原生验收传播屏障，只删除本次生成 schema。后端90%与前端既有门槛保持。本地结果与托管 CI 分开记录。

评分将观察记录绑定任务包/预演，将评分绑定精确运行/观察哈希。结构、范围、预算和摘录来源属于机械检查；缺失导出仍计入尝试分母，未尝试题另列。未评分的完成/语义值保持 null；部分评分显示已确认完成率下界和明确已评分子集。人工/模型覆盖率、均值和不确定性分开。服务端成功不是语义任务完成，子集不能满足完整任务包门槛。供应商来源和导入评分均为外部报告，不冒充独立认证。

评分模板使用 null，不制造分数。不自动套用回答裁判、不重试/回退、不自动代替操作者审批，也不签发发布合格结论。测试中的脚本决定仅为隔离虚构数据上的操作者模拟，不是人工审核证据。本阶段不改变业务 schema、API 或任务运行时。
