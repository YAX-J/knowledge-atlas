# ADR 0068 显式协作范围与已保存范围读取

[English](0068-explicit-workflow-scope.md)

- 状态：已接受
- 日期：2026-10-30
- 扩展 ADR 0064–0065/0067，复用 ADR 0061 的不可变上下文选择。不新增迁移，head 保持 `20261029_0019`。

## 决策

在协作页面接通既有 retrieval_mode、valid_at、snapshot_id、version_ids 参数。默认保持 BM25，向量/混合/RRF 仍需配置语义检索。可选 datetime-local 输入按页面展示的浏览器时区转换为带时区的 UTC 时间。历史问题清除/禁用当前代码分析，不提交代码/来源/版本参数；切换为知识整理时清除历史时间。

`useCodeContextSelection` 复用既有只读 analysis-contexts API 和 useLatestRequest 请求保护。项目/来源/开关变化使旧读取失效，清空旧选择，抑制往返切换/卸载后的迟到结果。元数据加载中、失败或选择失效时阻止付费提交，重试仅 GET。展示服务端优选快照或本地覆盖，二者互斥；校验成员与 99 个覆盖上限，披露元数据截断。当前来源保持已打开的不可变版本，未指定的相关本地文件在执行时选取，不在读取清单时冻结。后端仍在编译器/供应商调用前负责项目/仓库/时间/字节/来源范围的最终校验。

新草稿范围预览与保存结果分开。启动/列表/详情/恢复响应新增从既有保存请求投影的白名单 `scope`：retrieval_mode、valid_at、include_code_analysis、code_strategy、snapshot_id、version_ids。知识整理的问答字段为空，未使用的代码字段为空值/空列表；不返回原始请求、来源哈希、提示词或凭据。客户端类型兼容旧服务缺失/null scope。已保存范围只读，不自动填为新草稿或重放调用；既有提交 UUID/sessionStorage 行为保持。

## 影响与限制

用户可选择并回查请求范围，替代隐式 BM25/默认代码上下文。实际代码分析上下文仍独立保存在代码结果中。版本元数据有界，提交时可能已变化；显式失效选择被拒绝，不静默按默认范围付费回退。草稿问题/时间/选项不加入 URL，刷新后不自动恢复。本轮不增加认证、任意规划、自动逐节点续跑、来源同步或真实供应商质量实验。

## 验证

沿用用户选择的 Agent 执行验证。2026-10-30，聚焦前端 28 项/后端 31 项通过；最终完整前端回归 17 文件、127 项通过（配置范围语句 69.54%、行 74.21%，版本选择组合模块行覆盖 100%），生产类型检查/构建通过。完整后端 `KA_NATIVE_COMPILERS=1`：752 项通过、8 项显式用例跳过，语句覆盖率 95.26%，超过 90% 门槛。PostgreSQL 17.10 / pgvector 0.8.7：自有 schema 中 175 项通过，迁移往返/清理完成，应用标记未变。

桌面 Chrome 使用独立 agent-browser 会话和 8012/5182 专用端口。忽略的包装脚本在确认 qa_workspace 临时 schema 拥有全部表后，经正常导入/解析准备合成 TypeScript 版本和合成快照清单。浏览器检查显式旧本地版本、旧固定快照及实际返回上下文、草稿/已保存范围分离、读取失败禁用提交和只读重试、历史 RRF、时区转换（Asia/Shanghai 的 2010-01-01 10:30 → 02:30Z）、排除当前代码、刷新恢复、键盘焦点和长路径换行，无横向溢出。CLI fill 未填入原生日期控件，改用原生 value setter/input 事件验证，不声称检查日期弹层。模型调用使用本地替身，快照 SHA 为合成值，不是新的 GitHub 验收。专用浏览器/服务已关闭，浏览器 schema 已清理，输出保持忽略。

最终来源整理流程隐藏空草稿/已保存范围区域，回归及桌面本地替身审核入口复查通过。两次自有浏览器 schema 和专用服务均已清理。没有真实供应商调用、人工评分、冻结实验改动或新迁移；提交前检查空白、本地链接和暂存产物。
