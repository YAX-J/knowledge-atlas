# ADR 0025：从构造器初始化推断有界 Java var 接收者

[English](0025-constructor-initialized-java-var-receivers.md)

- Status: Accepted
- Date: 2026-10-21

## 背景

ADR 0022 通过显式声明的方法参数和直属局部变量接收者派生仓库内方法调用。`var validator = new Validator()` 已在初始化中明确给出类型，但此前大纲会遗漏其后续调用。忽略未知局部变量也可能错误回退到同名字段或大写类型。

## 决策

- 仅扩展方法体直属局部变量的完整 `new Type(...)` 初始化，支持可选 `final`。在屏蔽注释与字面量之后，接受限定类型名、平衡的泛型参数/diamond，以及参数中的嵌套圆括号。
- 仅推断构造器的原始类型名，在完整初始化结束后才可用，再沿用既有包/导入解析、仓库边界、按方法名判断歧义及稳定的来源/行号 ID。
- 不支持的 `var` 初始化保留未知绑定，遮蔽同名字段/类型，不生成猜测调用；显式 `this.field` 仍选择字段。
- 继续排除工厂返回值、链式表达式、强制转换、数组、条件表达式、匿名类/带花括号初始化、嵌套块局部声明、循环/资源头部绑定、通用数据流、泛型替换和重载/继承分派。
- 来源分块、接口形状、持久化、结果上限与正式图谱边界保持不变。本决策仅为上述构造器子集补充 ADR 0022 先前对 `var` 的整体排除。

## 影响

常见构造器初始化的协作者会显示在既有来源大纲中，无需迁移、前端变更、外部编译器或模型调用。结果仍为有界语法提示；不支持的形式会保守减少链接，避免错误回退到字段/类型。
