# ADR 0076：有界项目只读助手


- 状态：已接受；M1 本地替身验收通过
- 日期：2026-10-31

## 决策

按[项目 Agent 方案](../PROJECT_AGENT_PLAN.zh-CN.md)实现 M1，增加第四角色 `project_assistant`，复用固定版本 LangGraph 循环和现有 DeepSeek 适配器。函数调用表达 `call_tool`；严格终止动作仅 finish/ask_user，拒绝写入/提案及未知动作/字段。不重试、不回退、不上传外部追踪。

使用独立 assistant-task-v1 请求和 assistant-report-v1 结果。可回滚迁移 `20261031_0020` 仅新增 assistant_tasks，保留旧 AgentRun 状态、WorkflowRequest 和 QuestionRead。为安全刷新/重放，M1 提前实现 M2 的任务信封，但不提供会话、独立尝试表、队列、runner、补充输入、取消、确认或继续执行。Worker 不消费这些记录。

后端固定用户/项目、显式 ready 来源 UUID/哈希、可选已保存代码快照和知识时间。未选资料时仅检索正式知识。原始范围最多 20 份资料 / 200000 UTF-8 字节、500 分块 / 240000 分块字符，超限在传输前拒绝。精确本地 UUID 不展开最新版本；所选代码必须唯一归属所选仓库快照；历史知识请求不允许原始资料附件。

五项只读工具：search_sources、read_source_chunk、search_knowledge、search_symbols、read_source_range。正式知识沿用项目/时间隔离的 BM25，每次最多 5 实体 / 12 证据，嵌入预算为零。原始/源码工具仅访问所选版本。资料内容是不可信数据，不能充当授权。搜索最多 8 片段，读取最多 60 行 / 4000 字符，明确截断和语法警告。后端引用池最多 32 个 ID，由实际返回的文本、来源 UUID/哈希、可选精确分块/正式证据、路径/行号和适用的所选提交生成；原始引用不能伪装成正式证据。

任务上限仍为最多 8 次模型尝试 / 16 工具，单协调角色另受 4 模型 / 8 工具 / 230 秒限制。累计模型输入最多 160000 字符、工具输出 24000 字符、报告 JSON 16000 字符。既有 fenced save_progress 增加显式记录模型参数，默认保持 AgentRun。回调前保存调用预留，另存校验后的报告检查点。拒绝未提交 ORM 写入；项目归档、租约失效/过期或进度失败阻止后续调用/发布。事件仅保存白名单元数据，用户目标/产物保存在有范围的业务记录。

相同 UUID 提交和所有 GET/轮询/恢复只读保存状态；同 UUID 改输入返回冲突。过期 running 显示 interrupted；传输失败可能存在未知远端结果，仍保留计数。M1 不隐式继续，新 UUID 代表单独提交的新任务。ask_user 是已保存的成功补问结果，用户补充目标后新建任务。

报告使用 referenced/uncertain 条目；前者必须引用实际返回 ID，后者必须说明缺失信息。标记只表示附有引用，不证明语义正确、测试通过或正式知识。正式证据回答仍为 evidence-claims-v3，旧格式兼容保持。界面区分草稿/已保存范围，展示来源/用量/错误/补问和精确导航，采用文本插值，通过按项目 sessionStorage 读取恢复任务；旧工作流 URL 行为保持。

## 影响与验证

源码 schema head 改为 `20261031_0020`，不会自动迁移已安装业务数据库。异步可靠性、笔记、受治理写入仍属 M2–M5。本实现不授权新依赖、外部写入或付费实验。冻结输入/结果/账本及人工覆盖率 0% 保持，M1 真实质量未测量。

新增 API/网关/租约/重放、迁移和 Vue/组合模块回归。用户已选择 Agent 执行验证。聚焦61、完整后端1019通过/11跳过（95.44%）、原生257、前端140/覆盖率/构建、桌面及最终前端聚焦26通过；提交前记录差异/暂存检查。这些是本地工程验证，不代表真实供应商质量或远端 CI。[命令及预期结果](../PROJECT_ASSISTANT_M1.zh-CN.md)包括完整后端覆盖率 >=90%、前端覆盖率/构建、原生临时 PostgreSQL 升降级/回归、桌面浏览器和差异/暂存检查。
