# ADR 0079：有范围的助手动作与人工审批

[English](0079-governed-assistant-actions.md)

状态：已接受 · 2026-10-31 · M4

`assistant-task-v3` / `async_v3` 在 M2 持久化 runner 上增加写入能力。v1/v2 保持请求哈希、提示词、工具定义、预算和重放语义。v3 保存显式 `allowed_actions`、固定笔记修订，以及可选仓库 UUID 和40位提交 SHA。历史知识时间排斥原始附件和写入。默认授权为只读；只有授权解析时才能选未解析资料。

网关覆盖方案中的项目、资料、证据、代码、笔记、导入、解析、抽取、治理和报告矩阵，委托现有服务执行；正式知识只由现有人工领域操作写入。新草稿、确定性解析、不可变导入和待审核候选可在提交时显式授权后执行。导入绑定仓库身份和提交，每次 HTTP 请求前检查任务归属，沿用文件/文件树上限，仅把回执产生的资料扩展到任务范围。原文读取仍限20份/200000字节/500分块并披露截断。不提供 shell、任意文件系统、代码执行、发布或远程仓库写工具。

原生工具调用 ID 在任务 UUID 下派生操作 UUID。回执绑定规范参数；提案 SHA-256 包含用户、项目、任务、目标快照和完整内容。成功操作重放返回已存回执。已有笔记修改和候选确认/合并/SUPERSEDES/退役保持待审批，完整修改前记录和拟议输入可审阅。审批复查内容完整性、作用域及全部目标/证据版本，再在项目/任务锁和 savepoint 内调用现有服务。领域写入与审批/操作回执原子提交。版本变化保存冲突；拒绝不修改底层候选。同审批 UUID 重放不重复写入。

工具检查点先落库，再进入 `waiting_approval`。审批本身不发起模型请求、不重新排队。全部待审批提案处理后，用户显式继续，绑定保存版本/检查点，保留累计预算，只追加一次实际决定。新确认正式证据作为单独的审批结果提供；原知识检索时间仍固定。报告使用类型化 `assistant-report-v2`；最终或草稿产物可显式转成保留原始引用的可编辑笔记。

v3 协调者与专用角色共享8次模型/16次工具尝试、0次嵌入和230秒执行时间。协调者在总预算内最多8/16，支持导入→解析→抽取→审批→报告；专用角色各保持4/8。v2 协调者仍为4/8。调用前持久化尝试。模型或写操作结果未知时保留计数，继续前必须明确确认；不自动重试/排队。业务提交前检查执行归属，取消或租约失效会回滚迟到写入。角色预算覆盖由任务代码设定，模型不能修改。

迁移0023新增操作/审批表及等待状态。降级在移除审计表前关闭活跃 v3 执行；保留历史需恢复已验证备份。M5 发布与真实质量工作独立。本地替身成功不能衡量模型质量，也不授权供应商调用。
