# ADR 0063 实测驱动的索引规划


- 状态：已接受
- 日期：2026-10-29

## 决策

原始归属证据每批读取 500 个实体；已有嵌入只投影标识/模型/维度/哈希，不读取向量正文。待更新项保留 UUID/文本/哈希，避免释放读事务后 ORM 过期逐项重新查询。保持证据 UUID 顺序和原始归属哈希，防止身份合并将未来事实带入历史向量。供应商分批、复用和显式索引任务归属保持不变。

原生临时 schema 使用正常审核的 1k/10k 合成数据，每操作 20 个温缓存样本，校验前后计划指纹，记录 SQL/p95/Python 分配和冷索引请求估算；禁止供应商网络请求。规模报告与答案质量实验分开。公开文档 v3 测试集另行冻结，禁止用来调排序。

## 影响

规划查询数为 O(N/500)，实体/待更新项内存仍为 O(N)。测量不含供应商延迟和向量持久化，不证明生产容量；BM25 保留明确的 1000 实体扫描窗口。缺少代表性时序/规范身份向量测量时不新增缓存或 ANN 索引，也不能从字符数推断金额。
