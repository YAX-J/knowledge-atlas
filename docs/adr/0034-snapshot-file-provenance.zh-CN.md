# ADR 0034：查询已保存的快照逐文件来源


- 状态：已接受
- 日期：2026-10-22

## 决策

- 提供只读 `GET /projects/{project_id}/repositories/{repository_id}/snapshots/{snapshot_id}/files`，按路径/UUID 稳定分页（默认 20、最多 100）。计数和读文件前校验未归档项目、仓库与快照作用域。复用既有表及 head `20261022_0014`，不新增迁移/供应商/模型调用。
- 保留保存时的导入/复用/未变/改名/删除/跳过事实、原路径、blob、大小与跳过原因；返回完整性标记与已保存记录总数，不代表完整仓库。分页不能恢复原同步预算省略的文件；这不是 patch 或 Git diff。
- 外连接只投影来源/任务关联元数据，不加载原文或任务结果。来源 UUID 仅在用户/项目/仓库/来源类型一致时提供；任务还需匹配此来源及对应解析类型，兼容旧 Markdown 解析任务。缺失或不兼容引用置空，只读接口不修复它们；跳过项不提供来源跳转，ready 资料没有任务仍可读原文。
- 文件 URL 使用所选快照 Commit/路径与当前规范 remote，不依赖来源最近一次出现记录。生成链接前校验路径/SHA。删除路径不生成指向删除后 Commit 的文件链接，但仍可打开保留的本地来源。资料详情/证据沿用既有来源级定位，复用来源的展示路径可能不同。
- 新增只收 props/发事件的 `SnapshotFiles.vue`；应用请求序号屏蔽仓库/历史页/快照/项目变化或关闭后的旧文件响应。保留失败页号供重试，支持有界滚动、长路径、加载/空/错误/重试、键盘面板/原文焦点和关闭后返回入口。原文跳转复用解析/审核，不自动下载或抽取。

## 影响

用户可查看同步快照包含的已保存文件，并在改名/删除后阅读保留原文。不新增正式代码实体、时序替代、Git 历史/diff 或破坏性删除传播。阶段四仍在进行。现有安装仍需 head `20261022_0014`；本功能无新迁移，验收不修改业务数据。
