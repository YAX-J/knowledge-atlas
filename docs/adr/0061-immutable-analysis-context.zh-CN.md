# ADR 0061 不可变代码分析上下文

[English](0061-immutable-analysis-context.md)

- 状态：已接受
- 日期：2026-10-29

## 决策

扩展 ADR 0059：免费 `GET /sources/{id}/analysis-contexts`，显式调用分析可传 `snapshot_id` 或重复 `version_ids`。所有策略先选择上下文，再调用工具/供应商。快照采用保存的原路径与来源成员，后续来源改名不改变历史视图；默认最近完整快照，否则最近部分快照。本地每路径默认最新可分析版本，可明确指定一个相关版本；当前主文件保持所选来源。

按用户/项目/仓库和语言族隔离。拒绝混合上下文、外部 ID、主文件不在快照或同一来源多路径映射。先读元数据再载正文：最多 2000 行元数据、99 个相关文件、总计 20MiB，明确截断；选择描述最多 50 个快照、100 个重复组、每组 20 版本。快照中未解析来源明确算部分上下文。

## 影响

结果返回实际 commit/policy；重复同步不再将同路径多个版本混入编译上下文。若当前文件超出元数据窗口，可能明确拒绝。结果仍是静态声明身份，不安装依赖、不执行运行时/构建；正式图谱仍须人工写入。
