# ADR 0007 将已确认候选写入 PostgreSQL 正式图谱


- 状态：Accepted（已接受）
- 日期：2026-10-17

## 决策

扩展 ADR 0006：确认候选时，将其写入 PostgreSQL 正式实体、关系和证据表，与审核状态和审计事件同一事务提交。写入前再次校验证据和所属范围内的关系端点。稳定 UUID 与候选唯一引用保证重复请求幂等。重复提交相同确认还可补写旧版已确认候选，不重复调用模型或增加审核事件；关系可在同一事务中补写已确认的端点实体。

关系端点和证据归属使用带范围的复合外键。正式记录保留候选来源、置信度、状态和有效时间属性。首次有效时间取正式写入时间；内容语义上的历史定年和 SUPERSEDES 自动状态切换仍待后续开发。SUPERSEDES 保持新知识指向旧知识，不自动推断实体合并或跨批次去重。

图谱查询只读，限定用户和有效项目，并限制节点/关系数量。支持可选中心节点、双向一/二跳邻域、实体类型与有效时间过滤。前端负责布局，真实项目图谱与现有演示分开展示。节点和关系详情返回原始文件名、分块引用、摘录及后端计算的行号。本次不增加真实问答。

## 影响

迁移 `20261017_0005` 新增图谱表，不修改已有候选。旧确认可在审核页面显式重放。回滚删除正式图谱和证据，保留来源、候选与审核事件，之后可以重新补写。正式证据会阻止删除被引用分块，因此不支持破坏性重新解析。PostgreSQL 17.10 临时 schema 已通过迁移升级/回退/再升级、证据读取和并发重复确认。浏览器验证使用隔离 SQLite 和模拟抽取，真实模型质量与原生数据库浏览器验收仍待完成。
