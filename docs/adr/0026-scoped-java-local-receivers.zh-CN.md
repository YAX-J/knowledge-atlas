# ADR 0026：在有界词法块内解析 Java 局部接收者


- Status: Accepted
- Date: 2026-10-21

## 背景

ADR 0022 与 0025 通过方法体直属局部变量派生调用，包括构造器初始化的 `var`。普通嵌套代码仍无法连接，平面的局部变量表也不能区分兄弟块，或在局部绑定离开作用域后恢复外层字段。

## 决策

- 屏蔽注释/字面量后索引方法体花括号，支持普通块和带花括号的 `if`、`else`、`else if`、`while` 体；记录父块及结束偏移，不引入 AST 依赖。
- 显式局部类型与构造器初始化的 `var` 绑定归属于所在块，在声明/初始化结束后、所属块结束前对受支持子块可见。按最近可见局部变量、参数、字段依次解析，`this.field` 仍选择字段。
- 不支持的 `var` 初始化在词法生命周期内保留未知绑定，阻止回退到同名字段/类型；离开块后重新允许外层绑定。
- 保守跳过不支持的带花括号作用域及其头部中的跨文件调用：`for`、资源/异常处理、`switch`、lambda、匿名类、局部类型，以及含 `instanceof` 的分支。头部声明不能成为方法全局局部变量；本切片不实现全部 Java 控制流、模式、捕获或作用域规则。
- 接口形状、精确调用/目标行、稳定 ID、仓库/来源/结果上限、来源分块、持久化与正式图谱边界保持不变；仅对受支持花括号形式扩展 ADR 0022 与 0025 的嵌套局部变量排除范围。

## 影响

既有大纲可以连接普通嵌套协作者并区分兄弟块绑定，退出块后恢复外层字段和参数。不支持区域可能比此前返回更少提示，以避免通过未知局部绑定猜测目标。通用类型推断、工厂/链式 `var` 初始化、多变量声明、重赋值分析、重载选择与继承分派仍待后续处理。
