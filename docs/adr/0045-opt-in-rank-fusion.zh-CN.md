# ADR 0045：可选排名融合与在线证据分配

[English](0045-opt-in-rank-fusion.md)

状态：已接受

日期：2026-10-25

## 决策

新增显式 `mode=rrf`，协议 `bm25-vector-rrf-v1`；原 keyword/BM25/vector/固定 hybrid 排序不变。两路使用同一用户、项目、类型及有效时间，各贡献最多 100 个实体，按各路 `1 / (60 + rank)` 求和，缺席分支贡献为零，同分按名称和 UUID 排序。保留原始分数、两路排名、精确原文、词法扫描预算、索引数量与截断信息。不扩展仅靠图关系召回的邻居，排序分数不表示答案可信度。

RRF 需要通过本地嵌入配置校验；匹配索引为空时跳过供应商，仅保留词法命中，供应商故障仍显式报错。搜索默认 keyword 不变。问答接受 `retrieval_mode=hybrid|rrf|vector|bm25`，默认 hybrid。BM25 检索不请求嵌入，但找到证据后的回答生成仍需回答模型。

在线问答在前五个实体之间轮流选择证据，最多十二段独立原文。只按 `(source_id,chunk_id,start_line,end_line,quote)` 精确去重，保留首个正式证据 ID 及其实体归属；不同来源、位置和版本保持独立。模型只能引用实际发送的规范证据 ID，返回选中数、重复数及截断信息。不修改正式证据或知识。

## 影响

用户可显式比较融合方式，旧实验目录及 `line-evidence-v2` 评分不改。运行器新增 RRF，但仍要求嵌入授权及全新输出目录；其历史证据展开/回答重放不能代表新版在线问答分配的端到端效果。

通过模拟供应商的作用域、时间、排名、零调用和引用测试约束行为。本决策不附带新付费模型质量实验，也不声称普遍提升；RRF 仍可能返回无关片段。原始资料直搜、校准可回答性、实体合并与撤销不在本次范围。
