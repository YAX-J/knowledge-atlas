# ADR 0047：筛选知识与保留原文的全部实体归属


状态：已接受

日期：2026-10-25

## 决策

候选列表新增可选 `kind=entity|relation` 和最多 200 字符的 `q`，与已有来源/状态/类型/置信度筛选共同作用于计数和分页之前。查询只规范化空白，对名称/摘要作不区分大小写的字面子串匹配，转义 SQL 通配符。保留未筛选默认和整份来源审核统计。前端切条件回第一页，清空选择/预览并丢弃旧响应；审核后当前页消失时退回有效页。

治理新增问题 `kind` 筛选，在有界扫描结果上先统计类别、再筛选、最后限制结果数，返回 `counts_by_kind` 和 `kind_filter`。计数只代表实际扫描的当前知识范围，不代表完整语义质量。保持默认行为、稳定建议 ID、1000 实体扫描预算和只读边界。

新增显式双实体核对视图，复用既有授权详情读取。两份结果展示前校验 ID 与项目归属，分别展示原文并保留精确分块跳转。关闭、切项目/时间/类别或确认演化后使结果失效；不执行合并或知识修改。

在线问答继续按来源/分块/行号/引用精确去重并使用原规范证据 ID。新增 `related_entities`，保留引用同一所选片段的全部检索实体；将这些名称作为 `entity_names` 随片段交给回答模型。保留主要 `entity_id/entity_name` 和响应 `entity_ids` 的主要归属语义。模型引用仍只能使用实际发送的规范证据 ID，不合并正式证据，不混淆不同来源或版本。

## 影响

用户能按需处理审核队列、核对疑似重复的原文；同一引用不会丢失其他实体归属。原检索排序、回答输出校验、默认及历史实验保持不变。不新增数据库迁移或供应商依赖，不声称新模型质量提升。
