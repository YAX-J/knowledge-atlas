# ADR 0074：实验执行器隔离单题输出错误


- 状态：已接受，2026-10-31，基于用户“错误修复后重试”的授权。
- 范围：离线实验执行协议v4；不改变线上问答、模型提示词、Schema、排序、金标或裁判阈值。

## 决定

首次holdout运行在第5次回答出现 `QUESTION_OUTPUT_INVALID` 后整轮中止。失败正文未保留；一次明确授权的诊断重试通过原严格校验，不能宣称发现或修好了某个确定的模型字段缺陷。工程缺陷是将一个可观测的无效输出样本升级成整个实验无法完成。

显式 `--isolate-output-errors` 只隔离已取得检索结果的 `QUESTION_OUTPUT_INVALID`：保存本题检索、输入池、脱敏异常/固定约束代码和空答案，将该题计为系统输出失败，继续其他独立题。绝不重复调用失败题、不修补或伪造答案、不放宽引用/Schema校验。网络、认证、限流、预算、索引不全、证据归属和未知错误仍停止整轮。原默认v3失败即停行为保持兼容。

每种方法报告全部题数、有效答案数、无效输出数及覆盖率；失败题不能从分母悄悄消失，数值评分器的空答案语义仍为未评测，而不是人工正确/错误。全题遍历后有格式错误标记 `completed_with_case_errors`，不能写“全部回答通过”。

用户授权范围内可显式复用一条严格校验通过的BM25诊断答案：必须绑定数据/夹具/应用代码/回答模型/协议，重新比对完整有序检索证据及实际输入池；只有原文位置/文本完全一致且唯一时才映射临时UUID。输入、版本、模型或引用不匹配，在付费建索引前失败。保留来源指纹和原生成耗时；一条耗时来自诊断阶段，不能冒充全是同次连续运行耗时。复用不是旧答案补拆，也不是线上缓存或自动续跑。本轮诊断1次、主跑至多95次回答，总上限仍96；嵌入上限73。

裁判准备默认仍要求真实非空答案。显式 `--exclude-output-errors` 只将合法标记的无效输出放入独立排除清单，完整导出仍覆盖全部题；记录总数/可评数/格式失败数及排除清单哈希。不能生成替代回答、填人工分数或把可评子集当作全题质量。裁判调用仍须另外授权，零调用预演保留。

## 后果与验证

该执行协议在观察到首轮失败后修订，完整重试含一条诊断复用；必须披露，不声称完全未见或原预注册的单次运行。不使用测试题优化回答策略，模型仍可能持续产生无效输出。开发夹具/本地替身覆盖单题错误继续、基础设施失败停止、精确复用及拒绝变更、排除清单与覆盖率；真实结果另行记录。
