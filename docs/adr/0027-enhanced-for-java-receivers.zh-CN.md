# ADR 0027：通过有界增强 for 元素解析 Java 接收者

[English](0027-enhanced-for-java-receivers.md)

- Status: Accepted
- Date: 2026-10-21

## 背景

ADR 0026 已索引词法花括号作用域，但排除全部 `for` 体。常见的仓库内调用如 `for (Validator item : items) { item.validate(); }` 已显式声明元素类型，可以复用既有有界类型查找，无需集合类型推断或编译器依赖。

## 决策

- 屏蔽注释/字面量后，识别带花括号、无注解的单元素增强 for 声明，支持可选 `final` 和简单、限定、泛型类型。复用既有原始类型查找，不替换泛型参数，也不从集合推断元素类型。
- 元素绑定从循环体左花括号生效，到右花括号结束，对受支持子块可见；保留兄弟块隔离、外层绑定恢复和显式 `this.field` 覆盖。不支持的祖先仍排除整个区域。
- 增强 for 的 `var` 和数组元素变量保留未知绑定，循环体内不能回退到同名字段或大写类型；循环体内其他显式类型接收者仍可解析。
- 省略全部增强 for 头部调用。集合表达式不属于元素变量的循环体作用域，本切片不承诺表达式/控制流解析。
- 传统 `for`、资源/异常作用域、带注解增强 for 绑定、无花括号循环和其他不支持的执行作用域仍不在本子集支持范围内。接口形状、稳定来源/行号 ID、仓库/结果上限、来源分块、持久化和正式图谱边界保持不变。
- 仅对该增强 for 子集补充 ADR 0026 的全部 `for` 排除决策，无需迁移或前端改动。

## 影响

显式类型的循环协作者可在既有来源大纲中展示，包括嵌套和兄弟循环。未知元素绑定保持保守，不生成猜测链接。集合推断、泛型替换、重赋值/数据流、重载选择、继承分派和完整 Java 语义仍待后续处理。
