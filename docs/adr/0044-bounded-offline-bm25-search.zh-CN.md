# ADR 0044：新增有界离线词法检索基线

[English](0044-bounded-offline-bm25-search.md)

- 状态：已接受
- 日期：2026-10-25
- 扩展 ADR 0008，不改变原关键词字面语义

## 背景

冻结中文问题实验的关键词召回为零：空白切分与 AND 匹配把整段问题视为字面词项。固定混合低于向量的结果，也不足以支持在同一批 40 题上反复调参或静默替换历史结果。

## 决策

新增显式 `mode=bm25`，默认仍为 `keyword`，固定混合与在线问答不变。纯 Python 确定性分词：汉字单字/相邻二字片段、casefold Unicode 单词、完整标识符及标点分隔部分；对实体名称、摘要与可访问证据的拼接文本计算语料局部 Okapi BM25，无字段加权、学习得到的停用词或金标答案输入。正 IDF 为 `log(1 + (N-df+0.5)/(df+0.5))`，`k1=1.2`、`b=0.75`，依据 [Lucene 原始文档](https://lucene.apache.org/core/7_6_0/core/org/apache/lucene/search/similarities/BM25Similarity.html)。分词是应用选择，不是完整语言学分词，也不等同于 Lucene 分析器。

统计严格限定当前用户、项目、类型与时间可见的正式实体。最多扫描 1000 实体、5000 条有作用域校验的证据（每条排序摘录最多 2000 字符）、每实体 4000 排序字符。响应给出 `lexical` 元数据与截断原因；按分数、名称、UUID 稳定排序，优先返回匹配证据，精确原文和来源链接不变。分数不代表置信度或可回答性。不新增网络/模型请求、向量索引、持久化词法索引、图谱写入或迁移；大语料索引须后续实测决策。

语义查询先统计同模型/维度的可见索引；为空则直接返回空向量结果，不请求查询嵌入。配置在本地校验，保持未配置/维度错误语义。配置有效但索引为空的混合检索仍可返回字面/图关系命中，无需查询嵌入；不是供应商失败的通用回退。

## 后果与验收

前端新增明确标注免费、不混淆扫描与索引的选项，并阻止忙碌时重复提交。实验运行器允许 BM25 无模型授权运行，保存协议、词法诊断，并拒绝空/未知模式列表；不改历史结果或评分协议。

[开发诊断](../../evaluation/results/2026-10-25-bm25/README.zh-CN.md)使用完全相同的语料/图谱/索引指纹，供应商请求为零。它不是独立留出验证；代码定位与不可回答题即使表现差也保留。SQLite 与原生 PostgreSQL 检查公式、隔离、历史/归档、预算和空索引零调用。后续融合调优需要独立实验设计。
