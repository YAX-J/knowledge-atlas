# ADR 0043：有界只读仓库工具 Agent


- 状态：已接受
- 日期：2026-10-24
- 扩展：ADR 0041；无存储迁移

## 决策

保留 `single_step` 为兼容默认；显式 `strategy=tools` 使用普通 Python 的同步 DeepSeek function-calling 循环，不引入 LangGraph。首轮要求工具，中间轮自动选择，末轮禁止工具并要求结束。协议遵循供应商[工具调用说明](https://api-docs.deepseek.com/guides/tool_calls/)，关闭 thinking，不返回或记录内部推理。

仅暴露 `read_source_range`、`get_imports`、`search_symbols`、`find_references`、`get_type_members`，操作已授权的不可变来源快照与既有声明候选。不开放磁盘路径、SQL、Shell、网络、图谱修改或供应商内置工具。拒绝未知名称、多余参数、越界 ID；源码和工具返回都是不可信数据，不是指令权限。

预算为最多 4 轮模型、8 次工具、230 秒、累计工具结果 20000 字符、累计序列化输入 240000 字符；单次原文读取最多 80 行。超预算或非法最终输出显式失败。两种模式共用严格判定/目标 ID 与精确证据校验。结果与脱敏执行轨迹不持久化，不由解析 Worker 消费，不写正式图谱。

## 后果

前端提供选择、运行时上下文锁和工具名称/状态/耗时，不展示内部推理。金标集独立版本化：30 份公开合成片段、50 道行级案例、10 种语言变体。全部方式共用候选生成器，工具不能发明缺失候选。这是有界证据调查，不是通用规划或编码 Agent。候选覆盖、精确判定、精确率/召回率及耗时分别报告。

获准的真实验收保存在 `evaluation/results/2026-10-24-models`；冻结证据回答重放与在线检索分开。记录数值用量，未知账单和人工分数保持 null。人工标签只能来自真实评审。图表从冻结指标生成并记录输入哈希，不静默调整不理想结果。
