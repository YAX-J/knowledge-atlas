# ADR 0065 持久化协作与显式人工检查点

[English](0065-durable-reviewed-workflows.md)

- Status: Accepted
- Date: 2026-10-29

## 决策

增量迁移 `20261029_0019` 添加有作用域的 `agent_runs`，保存请求指纹、有界结果/事件/用量、执行 UUID 和租约。调用供应商前提交任务占用，最终更新检查执行归属。同一请求 UUID/输入返回已保存状态，不同输入冲突，其他范围保持 404。过期执行读为中断，不据此推断付费重跑授权。

用显式 LangGraph 边，在抽取或证据问答前可选执行代码分析。抽取只保存已校验候选后等待。保存候选/抽取任务/资料 ID；恢复时核对原文哈希和全部人工决定。正式入图继续使用原有审计审核事务；恢复不调用供应商或索引。历史问答不接受当前代码提示。同资料/策略成功抽取保持跨协作任务幂等。

提供启动/列表/读取/恢复接口和 Vue 协作页面，保存未知提交 UUID，重发前先读状态，防止跨项目迟到响应，展示保存的事件与原文/证据链接。hash URL 只用 GET 恢复。同步执行结束才保存事件，不提供实时流；进程崩溃不具备逐节点持久恢复。

## 结果

用户可以检查并显式完成协作，同时保留证据/审计边界。应用升级前先备份，并在自有临时 schema 验证迁移。失败或中断任务需要明确新建请求；本次不增加后台执行队列或自动付费重试。真实人工评分与模型质量实验仍需独立验收。
