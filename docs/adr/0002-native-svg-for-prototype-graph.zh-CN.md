# ADR 0002 原型图谱使用原生 SVG


- 状态：Accepted（已接受）
- 日期：2026-10-17

## 背景

初版前端需要尽量还原固定的视觉原型，包括不同节点形状、关系文字、时间控制和小型 Mock 数据集。在尚未明确真实图谱规模要求之前，引入完整图形库会提前增加打包体积和布局行为。

## 决策

交互式 Mock 图谱采用 Vue 渲染的原生 SVG。图数据与 SVG 标记分离，后端契约不包含画布坐标。

出现以下任一情况时，重新评估 AntV G6 或其他图引擎：

- 常见视图超过约 200 个可见节点。
- 需要自动力导向、层级、聚类或复合节点布局。
- 用户需要节点拖拽、套索选择、小地图或渐进式图展开。
- 性能测量表明 SVG 渲染已不再满足需求。

## 影响

- 原型布局确定，视觉样式可精确控制。
- 可以直接控制键盘操作和语义行为。
- 如果早期就需要布局、平移、拖拽和大图性能能力，必须自行实现。
- 未来迁移图形库时，应只替换渲染器和视图状态层，不改变 API 或领域类型。

## 评估过的替代方案

### 立即使用 AntV G6

暂缓采用。当前数据规模小、布局确定，配置图形库还不能验证真实布局需求。

### 仅基于 Canvas 的自定义渲染器

原型阶段未采纳，因为 SVG 的文本渲染、无障碍接口和基于 DOM 的检查更简单。
