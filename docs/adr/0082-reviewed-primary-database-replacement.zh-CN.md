# ADR 0082 人工审核主数据库替代

[English](0082-reviewed-primary-database-replacement.md)

## 决策

当校验通过的原文明确提及服务、主数据库角色和技术名称时，抽取流程可将该 `USES` 关系标记为 `primary_database`。系统也可从旧的已确认关系证据中识别这些词。

第一版按项目内规范化后的服务名称和实体类型识别主体。当另一条来自不同资料的主库关系与新区间重叠、早于新关系生效且证据可访问时，审核页可提出替代。多条重叠记录、缺少生效日期和重复值需要核对。普通 `USES` 关系沿用现有行为。

审核人查看新旧关系及原文，提交与预览绑定的校验值。后端在项目锁内重新校验，同一事务写入新关系、结束旧关系有效期并记录从新到旧的 `SUPERSEDES` 审核快照。新关系指向既有服务节点。历史查询沿用半开区间，每条关系保留自己的原文证据。替代建议需要单独确认。

## 存储

分类和确认回执存入候选 JSON，替代方向和前后快照存入现有审核事件。PostgreSQL 保存正式记录，无需数据库迁移。实体级知识变化继续使用现有演化流程。
