# ADR 0046：显式整批审核与只读索引状态


状态：已接受

日期：2026-10-25

## 决策

新增 `POST /projects/{project_id}/reviews/resolve-batch`，输入一份资料 UUID、1–100 个不重复候选 UUID 和 confirm/reject 动作。先校验全部选择均属于当前用户的有效项目与资料，再持有项目锁，按实体先于关系的顺序复用既有审核/提升路径，中间不提交。全部成功后统一提交；失败则回滚候选、审计和正式知识。同动作重试幂等，返回结果保持请求选择顺序。关系仍要求同任务的端点已确认，选择关系不会隐式选择或确认端点。

前端只选择当前页待审核候选，展示名称预览并要求最终显式操作。换页丢弃隐藏选择，未保存的编辑阻止批量操作，审核请求期间锁住项目、资料和主导航。请求超时可能使客户端无法判断结果，可刷新或幂等重试同动作。不引入撤销或自动确认。

新增无需供应商的 `GET /projects/{project_id}/embeddings/status?valid_at=...`。沿用用户、项目及有效时间隔离，统计可检索实体与匹配索引。最多检查 1000 个实体，按索引构建时相同的名称/摘要/证据顺序重算规范文本哈希；同模型/维度下哈希改变计为过期，没有匹配模型/维度计为缺失。eligible/indexed/missing 是全范围统计，current/stale 只覆盖实际检查的子集，须返回扫描预算与截断。服务配置就绪以布尔值返回，不泄露密钥，也不探测供应商连通性。状态检查不构建向量。

索引仍显式更新，原搜索默认不变。更新后刷新状态，切项目/时间时丢弃迟到响应。状态不代表答案质量。不新增迁移。

## 影响

批量审核减少重复点击，并保留来源、审计和事务边界。索引状态能区分行数量覆盖与内容新鲜度；截断时未检查部分仍可能过期。既有重建仍覆盖非归档范围，状态检查则遵循选定的有效时间。实体合并、审核撤销、自动索引和新模型质量结论不在本次范围。
