# ADR 0040：扩展代码多语言解析而不改变知识权威边界


状态：已接受

日期：2026-10-23

## 决策

通过固定版本的 Tree-sitter 语言 wheel 新增 Python、JavaScript/JSX、TypeScript/TSX、Go、C、C++、C#。统一扩展名、媒体类型及兼容解析任务注册表，扩展原上传、Worker、GitHub 同步、大纲和符号检索，不创建第二套导入或正式图谱写入链路。Java 保留原解析器、符号身份和仓库分析。

沿用来源类型字符串、`code_parsing` 和原分块表，无需迁移。保留精确整行证据和确定性 ID，显式标记有界/语法不完整；新语言不推断跨文件关系。通过可选 `rescan` 发现旧同提交快照中新支持的文件，不放弃默认缓存。详见[能力边界](../MULTILANGUAGE_PARSING.zh-CN.md)。

## 影响

部署需安装兼容的固定版本原生 wheel。解析仅处理语法，不编译/执行或调用模型；语法升级需复验及评估证据身份，不破坏性重解析已提升证据。旧完整快照发现新文件需显式重新扫描。自动知识、编译器语义与界面国际化不在本决策范围。
