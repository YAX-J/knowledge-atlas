# ADR 0077：显式持久化助手执行


- 状态：已接受；本地验证通过
- 日期：2026-10-31

## 决策

仅实现 M2。assistant-task-v2 提交保存 queued 任务并返回202，不调用模型；v1 继续同步200，旧 AgentRun 保持。独立 `python -m app.assistant_runner` 通过范围内行锁/skip locked 只认领 async_v2 排队任务，生成执行令牌和300秒租约，运行同一有界协调器。解析 Worker 不消费这些任务。GET 和事件/产物读取不执行、不恢复、不预留调用。

迁移0021 为任务新增执行模式、修订号和已测量执行毫秒，并增加 assistant_attempts、assistant_steps、assistant_artifacts、assistant_continuations。保留历史任务/结果，旧记录默认 sync_v1。降级删除新增执行历史，保留任务结果，把不再支持的 queued/cancelled 状态关闭为 interrupted；降级是维护操作，不是业务撤销。业务升级前验证备份/恢复并保留旧表内容指纹。

模型/工具回调前，与 fenced 用量/事件一起原子保存尝试预留。每项模型决策或单个工具结果校验后，将循环状态、后端引用池和已完成尝试一起提交。这些是有范围的业务检查点，不是运维日志；事件保持无正文。显式继续从最后保存的节点/工具之后恢复，不重复已保存的传输/工具回执。最终报告与类型化产物在归属保护下原子提交。检查点最多200000 JSON字符/16份，沿用 M1 来源/输出/输入/引用/角色预算。提交时固定知识时间，执行前复查来源 UUID/哈希及快照归属。不重试、不回退、不上传追踪。

过期执行转 interrupted，不自动重新排队；未结算尝试转 unknown，远端可能完成但本地没有回执。取消清除执行归属，阻止后续回调/发布，在途用量保留；迟到执行者不能保存结果。显式继续绑定唯一控制 UUID、精确任务修订/检查点，有未知模型结果时须确认；不可变回执让重复继续只读。不能修改范围或预算。任务/角色用量累计；执行时间是边界持久化的已测量活跃时间，排除停机等待，每次执行也检查剩余时间；未知传输时长不承诺精确墙钟度量。

类型化产物沿用 assistant-report-v1，轮询/游标事件回放和产物读取保持用户/项目隔离。界面默认 v2，轮询 queued/running，提供取消/继续/未知结果确认，并在未知传输/刷新时保存控制 UUID。补问保留 M1 的已保存 ask_user 结果；独立 input、会话、笔记、确认和写入仍属后续阶段。启动 runner 不授权供应商实验，只消费显式新提交任务。本轮零真实调用。
