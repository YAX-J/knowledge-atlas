# ADR 0018：显式导入有界的 GitHub 仓库快照


- 状态：已接受
- 日期：2026-10-20

## 决策

已登记的 GitHub 仓库只能通过显式的项目范围 API 或界面操作同步。后端解析用户指定的 branch、tag、commit ref（未提供时使用仓库默认分支），通过 GitHub REST 读取 commit 与递归 Git tree，并把最多 50 份非空 UTF-8 `.md`、`.markdown`、`.java` blob 送入现有来源导入服务。

一次同步累计最多下载 20 MiB，并保留单份来源 10 MiB 的既有限制。文件按稳定路径顺序处理；每个有效 blob 复用仓库范围的内容哈希去重，新内容继续创建既有解析任务。单份文本无效时标记为跳过，不回滚此前已导入文件。GitHub tree 截断、文件数量上限与累计字节上限都会通过截断结果显式暴露。

公开仓库无需凭据。私有仓库可以使用只保存在后端、仅具 Contents 读取权限的可选 `GITHUB_TOKEN`；令牌不返回浏览器，也不作为业务数据持久化。供应商请求使用可配置的 GitHub API 基址、固定 API 版本、有界超时和脱敏后的应用错误。

## 影响

- GitHub 内容进入与本地上传相同的不可变来源、解析、证据和审核链路，不会绕过校验或人工审核。
- 仅远程仓库与已关联 GitHub 的本地文件夹仓库使用同一个显式同步操作及仓库边界。
- 重复同步同一快照时，未变化字节会幂等复用已有来源和任务。
- 响应会返回解析后的 commit SHA，但本切片不把 commit 元数据持久化到每份来源，也不导入 commit message、不生成不可变 GitHub 证据 URL、不检测重命名、不删除远端已移除文件，也不执行定时或增量分支同步。
- GitHub 标记为截断的递归 tree 仍是部分结果。逐子树遍历、Webhook、GitHub App、Issue 与 Pull Request 均留待后续实现。
