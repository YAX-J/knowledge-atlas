# ADR 0008 带证据的项目关键词检索


- 状态：已接受
- 日期：2026-10-17

## 决策

检索先实现只读关键词搜索，范围为当前用户有效项目的正式实体，匹配名称、摘要和同作用域的证据摘录。待审核/已拒绝候选和关系不作为搜索结果；关系仍可通过实体详情及邻域查看。沿用图谱的归档与有效时间过滤规则。

使用 SQLAlchemy 参数化、忽略大小写的子串匹配，转义通配符并按字面搜索。查询长 1–200 字符，按空白切分为最多 8 个词，去重后要求每个词至少命中一个字段。中文短语按字面子串匹配，不做分词、词干、同义词或语义理解。

采用可复现的整数关键词得分：名称与完整查询忽略大小写后完全相同加 50；每个不同关键词命中名称/摘要/证据分别加 10/3/1，同一字段不按引用数量重复计分。同分按名称、业务 UUID 排序。该分数用于排序，不表示置信度。返回 `top_k`（1–50，默认 10）、截断标志、命中字段及每项最多 3 条证据，优先展示命中的摘录。所有字段保持用户和项目隔离。

接口仅接受 `mode=keyword`；vector/hybrid 返回 422。项目图谱提供独立搜索表单，与演示页头搜索及画布筛选分开；选择结果打开实体详情，当前画布没有该节点时加载其邻域。用请求序号丢弃切换项目、清空或更新搜索后的迟到响应。搜索不调用模型，不修改数据。

## 影响

不新增迁移或依赖，head 保持 `20261017_0005`。子串查询可能扫描项目记录，适用于当前小规模语料。索引/全文分词、向量嵌入、图关系得分融合、关系检索及真实证据问答仍属后续切片。原生 PostgreSQL 检查验证 SQL 行为；模拟抽取不代表真实模型质量已验收。
