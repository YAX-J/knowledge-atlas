# ADR 0078：可编辑笔记与不可变修订

[English](0078-immutable-note-revisions.md)

状态：已接受 · 2026-10-31 · M3

笔记是项目范围的原始材料。`notes` 保存稳定身份和当前修订指针；`note_revisions` 追加标题、Markdown、父修订、SHA-256、作者来源和原始产物/任务来源。服务不修改已有修订正文。人工保存绑定请求 UUID 和预期父修订；过期保存返回409并保留草稿。同 UUID 重放比对原始输入并返回对应不可变修订。

编辑器以600ms防抖保存，保留请求期间继续输入的内容，隔离项目响应，并把未完成草稿缓存在 sessionStorage。传输结果未知时先 GET 或显式同 UUID 重发；刷新不重放写入。冲突暂停自动保存。历史和引用按精确修订展示转义文本。原始搜索最多扫描100份当前笔记/200000字符并披露截断。任务最多附加20个精确修订/200000字符，不跟随“最新”指针。

Agent 草稿是带不可变来源记录的可编辑笔记。已有笔记提案包含完整修改前后内容及预期父修订，按 ADR0079 审批。人工编辑报告草稿后保留原始引用记录，但不宣称修改后的文字仍被这些引用支持。

`note_sources` 把显式选定修订映射为一份不可变 Markdown 资料和解析任务。快照幂等创建，不产生正式图谱记录。只有现有抽取和人工审核路径能够提升证据。笔记引用使用 `kind=note`、笔记/修订 UUID、标题、哈希、精确行号及摘录，不伪造资料/分块/正式证据 ID。正式证据及 evidence-claims-v3 保持原契约。

迁移0022新增三张表。降级删除笔记、历史和映射，必须保留已验证备份；它是维护操作，不是业务撤销。PostgreSQL 仍是唯一业务库。本阶段不增加协同编辑器、通用记忆库或新图谱类型。
