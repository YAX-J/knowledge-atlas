# ADR 0071：有界符号缓存与轻量协作历史


- 状态：接受
- 日期：2026-10-30

## 决策

符号搜索先校验当前用户/项目/仓库/来源就绪状态和扫描预算，再缓存不可变符号元组、截断和语法错误标记。键包含用户、项目、来源 UUID、实际内容 SHA256、语言、显式解析器版本和解析预算；不同来源版本不混用派生符号 UUID。进程内加锁 LRU 最多128项、保守计量元数据8 MiB，不保存原文、语法树、解析器实例、任务映射、URL 或访问授权。分块、任务和 Git 链接实时读取。解析器变更须升级 SYMBOL_PARSER_VERSION，依赖升级需重启进程。并发冷请求可能重复计算，但不共享解析器。缓存不持久化/不跨进程；计量字节不是进程 RSS。

协作列表新增可选 summary=true，默认仍返回历史完整格式。摘要仅含 id/project_id/source_id/kind/status/error_code/created_at/updated_at，SQL 不读取 result/events/request/usage，共3次 SELECT。Vue 列表请求摘要，选中/恢复/刷新已选任务时才读完整详情。完整列表批量计数和来源/任务/候选归属检查保留，过期状态仍为只读判断。不增加迁移。

从 AgentWorkspace 提取 AgentWorkflowForm，保持草稿重置、显式版本、历史时间排除当前代码及付费提交规则。解析共用冻结数据结构移至 analysis/structures.py，原 Java/Tree-sitter 导入名仍可用；ID、精确行证据和解析语义不变，语法记录不写正式知识。

## 测量与限制

新增[版本化测量](../../evaluation/performance/2026-10-30-cache-lexical-v2/README.zh-CN.md)，保留旧实验。50份合成代码的冷解析326.806 ms，同键热读取0.538–0.618 ms，输出哈希一致，150次重复访问全部命中；这不包含数据库/HTTP。每条256事件的50条合成任务由1777746降为13196字节 JSON，不代表所有真实页面或压缩后大小。

词法 v2 在物理归属已校验的临时原生 schema 中，经正常显式合成审核创建1000/10000个实体。两种词法模式均扫描全部语料；开启 tracemalloc 的服务调用中位耗时千级365–497 ms、万级3358–3969 ms，峰值 Python 分配至多7.24 MB。每个查询/模式排除一次预热，再采3次；报告中位数，不声称可靠 p95 或生产 SLA。不代表模型质量、RSS、数据库内存、冷启动或 HTTP 延迟。小规模合成测量不足以单独支持新增索引或调整排序。临时 schema 均删除，应用标记保持0019。

验证：KA_NATIVE_COMPILERS=1 完整后端811通过/8跳过，语句覆盖率95.63%；原生233通过，包含迁移升/降/升、物理归属及清理，应用迁移标记保持。前端18文件/133通过，配置范围语句覆盖率69.90%、行74.50%、表单行97.56%，生产构建通过；最后评估策略元数据的27项替身回归通过。Chrome1440×900 检查真实 API 摘要字段/GET详情、空/加载/读取错误与重试、持久化刷新不重放、精确原文及符号定位、键盘可见焦点、滚动和无横向溢出。命名浏览器和记录的服务/schema已清理，截图留在忽略的 output/ordered-optimizations-20261030。真实 Jev/DeepSeek/嵌入调用均0。
