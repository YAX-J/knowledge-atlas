# ADR 0069：回答结论逐条关联证据


- 状态：接受
- 日期：2026-10-30
- 取代 ADR 0011 的平铺模型输出部分；引用归属和检索范围不变。

## 背景

整段回答的引用列表合法，仍无法看出每项结论使用哪条原文。一段正文也可能混有据事实和无据细节。已有会话及协作检查点保存平铺回答，冻结实验必须保留原有解释。

## 决策

真实模型输出采用 `evidence-claims-v2`：1–8 条 claims，每条包含 text（1–500 字符）、status（supported 或 insufficient）和不重复的 citation_ids UUID。有据条目必须引用，不足条目不得引用，文本应明确无法确认之处。跨条可复用引用，全答最多 5 个不同引用，连接后最多 4000 字符。仅全部条目有据时整体 supported=true，否则 missing_information 必须非空。部分有据时保留有据条目。

模型不生成独立整段正文或顶层引用列表。服务端以双换行连接条目文本，按引用首次出现顺序生成去重列表，保留 answer/evidence/entity_ids 的主实体归属行为。所有引用必须属于本轮用户/项目/历史时间范围内的检索池，包含只读工具追加的证据。越界仍返回 QUESTION_EVIDENCE_INVALID；单轮/工具结构错误分别为 QUESTION_OUTPUT_INVALID/CALL_AGENT_OUTPUT_INVALID，不自动重试。无检索证据直接生成一个不足条目，不调用供应商。

真实供应商和工具循环均严格解析 ClaimAnswerDraft；旧 AnswerDraft 只供旧诊断适配器/夹具保留。新实验清单记录回答协议，不改冻结数据/结果及候选抽取提示词身份。本轮不运行付费实验。

QuestionRead 新增可空 claims、answer_protocol，旧会话和协作 JSON 无需迁移仍可读取，不推断逐条对应，不回放模型。新回答沿现有 JSON 检查点持久化。前端 AnswerClaims 供问答/会话与协作共用，每条引用经既有证据定位打开精确来源/分块；缺失 ID 不猜测其他来源。历史回答保留平铺正文并标明旧格式。所有内容使用文本插值。

## 影响与限制

Schema 能发现漏引、支撑状态组合矛盾和检索池外 UUID，不能证明引用在语义上支撑结论、模型正确拆分了每个事实，或没有将断言错误标为不足。页面使用“附有引用”并提示核对原文。真实人工盲评仍由用户稍后完成，不增加第二次模型核验或付费请求。迁移 head 保持 20261029_0019，累计付费账本仍为 84 次模型 /61 次嵌入尝试。

## 验证

沿用用户已选择的 Agent 执行。后端聚焦覆盖严格 Schema/供应商解析、部分有据、跨项目引用拒绝、旧持久化回答读取与同 UUID 重放、工具漏引不自动重试、会话和评估兼容。前端覆盖结论引用顺序与 evidence 顺序不同、精确跳转、不足条目、安全文本、不可定位 ID、旧记录和协作只读恢复。完整后端覆盖率、原生自有 schema 验收、前端覆盖率/构建、桌面 Chrome 本地替身走查的实际结果执行后追加于此。原生夹具不代表模型质量。

实际结果：`KA_NATIVE_COMPILERS=1` 后端 **773 通过 /8 跳过**，语句覆盖率 **95.57%**；原生 PostgreSQL17.10/pgvector0.8.7 **195 通过**，迁移升/降/升通过，临时 schema 已删除且应用迁移标记不变。前端 **132 通过 /18 文件**，配置范围语句覆盖率69.73%、行覆盖率74.42%，严格类型检查及生产构建通过。Chrome1440×900 使用真实 API、自有临时 schema 和本地供应商替身，覆盖无证据拒答、部分有据、精确第6–8行分块焦点、持久化会话刷新、工具协作保存条目、旧格式提示、引用按钮键盘可见焦点、面板滚动和无横向溢出。浏览器无运行错误；命名浏览器、记录的专用服务及 QA schema 已关闭/删除。截图留在忽略目录 output/answer-claims-20261030。不产生真实模型调用、外部同步或人工评分。
