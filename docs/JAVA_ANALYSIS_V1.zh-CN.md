# 仓库内 Java 分析 V1

[English](JAVA_ANALYSIS_V1.md)

V1 是有界、只读的源码大纲与调用候选分析，不是 Java 编译器或运行时调用图。结果来自已上传/解析的不可变来源，保留原文行号和确定性符号 ID，不能绕过审核或自动进入正式图谱。阶段四还包含独立的 GitHub 与评估工作，本功能包不代表整个阶段完成。

## 能力边界

静态导入扩展（[ADR 0030](adr/0030-java-static-import-calls.zh-CN.md)）增加显式/通配导入，把未限定调用链接到同仓库其他 ready 来源中的可访问静态方法。成员名称保守阻止导入回退，包括参数数量不符的情况；显式导入阻止通配回退，即使所属类型缺失。`this`/`super` 调用不使用导入。结果使用 `receiver="import static"` 和原目标符号/行号，保留重载/版本歧义。私有/非静态方法、不可访问的导入类型/方法、外部依赖、静态导入嵌套类型/字段及完整访问/类型语义仍不支持。成员查找不完整时不回退导入。

静态工厂扩展（[ADR 0036](adr/0036-bounded-java-static-factory-var-receivers.zh-CN.md)）只从完整 `Type.factory(...)` 初始化表达式推断普通方法体局部 `var`；要求所有可访问的仓库内静态候选对同一个可解析仓库内返回限定名达成一致。绑定从声明后生效并保留现有词法遮蔽。候选缺失、不可访问、非静态、私有、返回外部类型或返回类型不一致时，局部变量保持未知。

| 范围 | V1 行为 | 明确保留的限制 |
| --- | --- | --- |
| 来源结构 | 顶层类型、常规字段/方法、精确分块与行号 | 不是完整 AST，不提供嵌套/生成类型语义 |
| 接收者 | 直接类型、当前类型字段、参数、词法局部变量、构造器初始化 `var`、返回类型唯一的类型限定静态工厂 | 不做通用工厂/链式推断、重新赋值数据流、泛型替换或运行时数据流 |
| 块体 | 普通块/if/else/while/try/catch/finally、带花括号的增强/传统 for 与资源 try | 不提供通用无花括号控制流、switch/模式/lambda/匿名/局部类型语义 |
| 头部绑定 | 传统 for 单变量声明；多个资源声明或既有引用；增强 for 与 catch 参数 | 省略头部调用；带注解/复杂/多变量声明头部排除；未知 `var`、数组元素与联合 catch 只遮蔽、不猜测 |
| 继承 | 仓库内 extends/implements 候选、原目标 ID、未限定/this/super 调用、按签名抑制覆盖及菱形去重 | 不选择运行时实现；排除私有/构造器/接口静态方法继承；完整访问/类型检查延后 |
| 重载 | 同文件及跨文件调用按实参数量和可变参数筛选 | 同数量类型重载保持歧义；泛型/比较等不确定表达式不缩窄候选 |
| 安全 | 维持仓库/用户/项目与 ready 边界、重复版本歧义、不执行编译器或服务 | 未导入或未解析来源不能提供目标 |

`resolved` 仅表示上述规则内唯一候选，不保证 Java 编译通过或运行时分派目标。完整 Java 语义、外部依赖/构建系统集成及进一步语法覆盖属于独立后续工作。支持多行头部；块体声明仍沿用按行识别的单变量子集。工厂推断不包含链式、强制转换、条件表达式、实例、未限定名/静态导入、头部绑定及重新赋值形式。

## 上限

保留既有上限：200 符号、500 同文件调用、100 份相关 ready 来源、20 MiB 相关原文、400 相关类型，以及各 500 条类型关系/相关方法/跨文件调用。单次继承查找另设 256 状态预算；继承环及预算触顶设置 `truncated=true`。省略目标不能留下悬空响应边；菱形路径和重复不可变版本按符号 ID 去重，不按类型名称合并。

## 统一验收

使用既有后端虚拟环境，不需要 GitHub/LLM 令牌、前端或数据库迁移。测试使用隔离 SQLite 和夹具，不代表真实供应商或原生 PostgreSQL 验收。

```powershell
# backend/
.\.venv\Scripts\python.exe -m pytest tests/test_java_static_imports.py tests/test_java_v1.py tests/test_java_structure.py tests/test_parsing.py
.\.venv\Scripts\python.exe -m pytest
# repository root
git diff --check
```

预期：测试全通过；目标 ID/行号精确稳定；退出作用域恢复外层绑定；头部变量不泄漏到 catch/finally；保留歧义；继承环/预算可终止；仓库隔离不变；没有跟踪密钥/依赖/构建产物。综合 API 夹具覆盖“资源 try → 传统 for → 继承方法 → 参数数量筛选”的完整上传/解析/查询路径。功能包实现收齐后统一验收，再修复/复验失败项，不能用单个小功能测试替代整体完成判定。
