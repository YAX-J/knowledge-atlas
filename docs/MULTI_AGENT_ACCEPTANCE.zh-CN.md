后端目录复现：

```powershell
$env:KA_NATIVE_COMPILERS='1'
.\.venv\Scripts\python.exe -m pytest --cov=app --cov-fail-under=90 --cov-report=term:skip-covered
.\.venv\Scripts\python.exe -m scripts.verify_native
```

前端目录执行 `npm run test:coverage` 和 `npm run build`。原生验收需要已安装 PostgreSQL/pgvector；编译器验收使用 Java/Node/Go。脚本从本地配置读取连接信息，不打印凭据。完整测试中跳过的项目需显式公开 GitHub 验收或原生专用运行器；后者已单独执行。

浏览器使用8010端口的 `scripts.qa_workspace`、5180端口的 Vite 和独立 Chrome 会话。真实 HTTP、解析、候选、审核、图谱、任务持久化与编译器适配运行，模型和工具调用协议使用替身，验证的是集成而非模型质量。首轮资料抽取替身引用闭合大括号，只用于检查人工检查点；后续问答/编译器检查使用公开证据 `@Column(name = "visit_date")`，验证了精确原文焦点。浏览器、自有服务及两个记录的临时 schema 均已关闭/清理，浏览器测试未向应用库写入知识。备份、日志、截图留在忽略的本地输出目录。

最初两处原生测试断言错误统计了其他已提交项目的夹具，已改为按本项目/来源过滤，最终完整和原生回归均通过；没有删除生产作用域校验。

当前明确保留的限制：同步执行，结束后持久化最终事件，不提供实时流、崩溃后的逐节点恢复或自动付费重试。API 支持代码版本选择；协作页面当前使用默认固定上下文。真实人工盲评、私有 GitHub 授权、Docker 和远端 CI 保持此前的待验收状态，不因本次重构算作完成。
