# 实验讨论草稿与固定演示脚本


本文件为可纳入论文的Markdown草稿及答辩材料，不表示已修改或定稿Word论文。数值来自[完整问答重试](../evaluation/results/2026-10-31-holdout-v3-run2/REPORT.zh-CN.md)与[457请求裁判报告](../evaluation/results/2026-10-31-holdout-v3-clef-run1/REPORT.zh-CN.md)，无需再调用模型。

## 可使用的论文实验段落

实验以7份固定提交的公开技术文档构建24道问题，覆盖直接事实、跨文档、历史截面和不可回答场景，比较BM25、向量、固定融合与RRF四种检索方式。各方法使用相同审核夹具图谱、索引及回答配置。检索评价沿用按来源、行号与文本匹配的Evidence Recall@5；模型自动评审分别判断答案正确性、完整性、拒答合理性及逐条结论的引用支持。人工评分覆盖率为0%，参考题和事实由Agent编制，不作为独立人工金标。

四组共形成96条执行记录，其中91条通过结构校验，5条因整体支持状态与结论状态不一致被拒绝。BM25的Evidence Recall@5为90.00%，其余三种方法为97.50%；这些数值衡量证据检索，不是答案语义准确率。Clef裁判将91条有效答案中的83条标为正确。按全部执行记录统计，判正确标签为83/96，另外保留8条模型判错与5条格式失败。逐方法总题数均为24、可评分数为22/24/23/22，不能仅比较有效子集百分比而省略系统输出失败。

在共同有效且已评分的22题上，四种方法均得到20个正确标签，表明本样本的原始全题标签差异不能直接解释为普遍质量差异。该交集是补充分析，有效输出筛选仍可能产生偏差，不能证明等效或替代全题结果。183个带引用结论中103个获得高置信双序支持，80个被标为不确定；拒答合理性的全部91条判断低于0.8置信度。因此，当前证据支持功能链路、覆盖率与失败可追踪性的报告，但不足以证明高可靠的语义引用或拒答质量。

实验局限包括单个模型裁判、未校准置信度、相关小样本、Agent参考事实、审核夹具回放以及缺少独立人工评分。测试文档与开发材料共享FastAPI框架概念，不属于未见领域/仓库验收；历史时间是文档可用性及研究审核时钟，不证明API首次发布时刻。执行协议在首轮失败后修订，并复用一条经完整输入核对的诊断答案，必须披露。后续研究应在独立开发夹具重现版本和跨文档证据问题，并用新的独立测试检验修改，不基于本holdout调提示词、排序或阈值。

## 可引用的结论边界

- 可以说明：四种检索方案使用相同冻结输入；全部96题有执行记录；错误和缺失评分没有隐藏；引用能回到确切原文；模型评审结果可按输入/配置指纹复查。
- 不能说明：系统人工正确率91.21%、引用语义已保证、Vector普遍最优、拒答质量已可靠、自动抽取达到该质量、完整私有仓库已经验收。
- 若写“91.21%”，须完整写作“可评子集上裁判给出正确标签的比例83/91”，同时报告全部96题、5条格式失败与人工覆盖率0%；不将其简称系统准确率。
