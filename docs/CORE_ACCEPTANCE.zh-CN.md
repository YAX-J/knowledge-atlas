## 原生隔离事故与恢复

首版原生脚本错误地只依赖 `search_path=temp,public`，导致 Alembic 版本表及业务表回退，新增四个合成项目并推进 public 版本标记。该次不能作为隔离验收通过。用户明确批准仅恢复四个已定位夹具 UUID 及本轮空列/迁移变化后，守卫事务核对开发用户、时间、全部合成原文/哈希，只删除这些夹具，恢复原业务版本 `20261021_0013`，保留既有资料。删除的合成夹具无备份但可重建。

修正后显式设置 `version_table_schema`，测试前核对全部本地核心表及空项目表，清理后核对 public 标记。后续原生验收从完整新建临时 schema 通过，public 标记未变。禁止对业务 schema 做降级验收或夹具清理。降级 `0015` 会丢失演化/审核记录而不撤销实体有效期；业务迁移前须备份。
